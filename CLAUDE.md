# down.guide

The GitHub home of [down.guide](https://down.guide), a free, real-time feed of outages and incidents for agents and people: docs and issue forms, no source code. Usage docs are in `README.md`.

## About

This repository mirrors files maintained in Sazabi's private monorepo. A maintainer publishes them here by hand, so this copy can trail the running service; there are no releases. Do not commit directly or open pull requests: direct changes are overwritten on the next sync.

## Issues & support

File issues here (wrong data, missing providers, probe false positives, bugs) or use down.guide's send feedback form. Report security problems in down.guide itself to [security@sazabi.ai](mailto:security@sazabi.ai), never in a public issue.
