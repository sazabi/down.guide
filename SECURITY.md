# Security Policy

## Reporting a vulnerability in down.guide

If you find a security vulnerability in down.guide itself (the site, feeds, API or MCP server), email [security@sazabi.ai](mailto:security@sazabi.ai). Do not file a public GitHub issue.

We will acknowledge your report within 5 business days and aim to resolve critical vulnerabilities within 90 days. We will coordinate a public disclosure date with you before publishing.

## Problems at other providers

down.guide reports other providers' outages; it doesn't operate their services. Report a security problem in someone else's product to that provider. Please don't post one in this repository's issues.

## Supported versions

down.guide is a hosted service with no releases. We fix the live service at https://down.guide.

## Out of scope

- Vulnerabilities in third-party dependencies (please report upstream; we track and update)
- Denial-of-service attacks requiring physical or privileged access
- Wrong incident data copied from a provider's status page (open an issue instead)
